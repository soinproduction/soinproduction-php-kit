# SP CF7 UI Select

Предоставляет `custom_select` как WordPress shortcode и form tag Contact Form 7, включая tag-generator и интеграцию с mail tags.

Отрендеренному контролу нужен frontend JavaScript Custom Select проекта, который создаёт отправляемый hidden input. Required-валидация проверяет только непустое значение; добавляйте server-side allow-list, если значение влияет на цену, права или другую доверенную логику.
