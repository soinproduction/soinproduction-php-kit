# SP CF7 Icon Generator

Добавляет диалог генератора UI Icon в редактор Contact Form 7.

Диалог читает `uploads/ui-icons/manifest.json` и вставляет WordPress shortcode `sp_icon` с выбранной иконкой, размерами и CSS-классом. Модуль не регистрирует отправляемое поле CF7: shortcode отвечает только за представление и требует подсистему UI Assets проекта.
