# SP CF7 Redirects

Добавляет в редактор Contact Form 7 режимы Default, Redirect и Modal и выводит соответствующие `data-*` атрибуты в wrapper формы.

Модуль предоставляет только metadata. Он не содержит browser listener, который перенаправляет посетителя или открывает modal после отправки: это поведение должна реализовать и протестировать подключающая тема.
