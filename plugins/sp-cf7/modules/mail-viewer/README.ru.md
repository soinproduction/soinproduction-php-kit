# SP CF7 Mail Viewer

Сохраняет подготовленные компоненты писем Contact Form 7 в приватном post type `sp_cf7_mail` и показывает их в Contact → Mail Viewer.

Модуль хранит максимум 300 записей: содержимое письма, отправленные поля, данные получателя/отправителя, пути вложений и IP посетителя. Перехват выполняется до результата почтового транспорта, поэтому сохранённая запись не подтверждает доставку. Ограничьте доступ и определите политику privacy/retention.
