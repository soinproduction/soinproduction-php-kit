# SP Author Meta

Добавляет переиспользуемый metabox автора для выбранных post types. Подключите platform-модуль `sp-author-meta`, затем явно зарегистрируйте нужные типы записей.

```php
sp_register_author_metabox( [ 'blog', 'project' ], with_photo: true, with_position: true );
$author = sp_get_post_author( get_the_ID() );
```

`sp_register_author_metabox()` управляет полями фотографии и должности. `sp_get_post_author()` возвращает нормализованные имя, ID/URL фотографии и должность. При сохранении проверяются nonce и право редактирования записи.

Для каждого WordPress-пользователя модуль добавляет поле **Author photo** в раздел **Users → Profile** (или в форму редактирования пользователя). Фото сохраняется в user meta `_sp_author_photo_id`. В режиме **Select user** метабокс и фронтенд автоматически используют актуальное имя пользователя и это фото; смена данных профиля применяется ко всем связанным записям. Старое post meta `_author_photo_id` используется как fallback для ранее созданных записей, пока в профиле не назначено фото. В режиме **Custom** имя и фотография по-прежнему сохраняются отдельно у записи.
