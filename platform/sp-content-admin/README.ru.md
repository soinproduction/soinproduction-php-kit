# SP Content Admin

Поддерживает ограниченную роль `content_admin` на основе прав Administrator, но запрещает операции управления плагинами. Также скрывает недоступные пункты меню и admin bar.

Подключается именем `sp-content-admin`. Для проверки роли используйте `sp_is_content_admin()`. Основное ограничение работает на сервере через `map_meta_cap`; скрытие UI является дополнительной мерой.
