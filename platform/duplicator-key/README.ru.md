# Duplicator Key

Проектная compatibility-подмена Duplicator Pro, работающая только на административных экранах Duplicator. Подключайте её лишь в окружениях, где это поведение действительно требуется.

Модуль обращается к внутреннему API Duplicator и может сломаться после обновления vendor-плагина. Считайте его приватным compatibility layer и проверяйте при каждом обновлении Duplicator.
